A projekt elkészítésének ütemterve, hetekre lebontva:

1. Ismerkedés a technológiával
2. Architektúra, alaposztályok megtervezése
3. Alaposztályok megvalósítása, kezdetleges megjelenítése
4. ORM, adatbázis konfiguráció
5. Kliens-szerver kommunikáció megtervezése
6. Objektumok sorosítása, hálózati kommunikáció megvalósítása
7. Felhasználó azonosítása, autentikáció
8. Felhasználói oldal UI
9. Kvízek létrehozásának megvalósítása
10. Kvízek létrehozásához UI
11. Kvízek kitöltése, lebonyolítása
12. Kvízek kitöltéséhez UI
13. UI további kidolgozása, finomítása
14. Dokumentáció kiegészítése
15. Bemutatás
